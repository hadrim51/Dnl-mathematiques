1. Objetivos matemáticos

Modelizar.
Traducir una situación mediante variables y una fórmula dada.
Calcular.
Sustituir valores, respetar los signos y comprobar un resultado.
Representar.
Completar una tabla y situar puntos de un perfil.
Razonar y comunicar.
Validar una restricción y redactar una conclusión en español.
Marco del nivel: se utilizan proporcionalidad, función cuadrado, tablas de valores, ecuaciones sencillas, valor absoluto y lectura de gráficos. No se utiliza cálculo diferencial ni geometría analítica avanzada del espacio.

2. ¿Qué significa modelizar?

1. Situación.
Identifico las cantidades útiles y la pregunta.
2. Modelo.
Elijo variables, unidades y una relación matemática.
3. Cálculo.
Obtengo resultados mediante sustituciones, tablas o gráficos.
4. Validación.
Comparo el resultado con la situación y con sus restricciones.
Idea clave: un modelo no es la realidad completa. Conserva algunos aspectos, como altura y forma, y deja fuera otros, como materiales, cargas reales o coste.

4. Tres modelos dados

4.1 Proporcionalidad: z = kxy

z = k × x × y

Para x e y fijos, z es proporcional a k. Si uno de los factores vale cero, entonces z = 0. El signo depende de los signos de k, x e y.

4.2 Función cuadrado: z = x² − y²

z = x² − y²

Se calculan primero los cuadrados. Si |x| = |y|, entonces z = 0. Al fijar una variable, aparece una parábola sencilla.

4.3 Modelo contextual de hiperboloide

x²/4 + y²/4 − z²/9 = 1

Esta ecuación se utiliza únicamente para sustituir z = 0 y reconocer la sección x² + y² = 4. No se pide estudiar la superficie completa.

5. Métodos paso a paso

Método A · Sustituir.
  1. Copio la fórmula.
  2. Escribo los valores entre paréntesis.
  3. Calculo productos y cuadrados.
  4. Compruebo el signo y la unidad.
Método B · Completar una tabla.
  1. Calculo una fila cada vez.
  2. Conservo las columnas intermedias.
  3. Compruebo simetrías o regularidades.
Método C · Estudiar una sección.
  1. Fijo la variable indicada.
  2. Sustituyo y simplifico.
  3. Reconozco una recta, una parábola o un círculo.
Método D · Validar una restricción.
  1. Calculo z y después |z|.
  2. Comparo con el máximo autorizado.
  3. Si es necesario, reduzco |k| y vuelvo a comprobar.
