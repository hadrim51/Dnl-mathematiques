3. Resumen matemático: sensores, parámetros y parábolas

3.1 Cadena matemática de una interacción

Una instalación interactiva se modela como una cadena: sensor → dato numérico → regla → parámetro → función → salida visual.

3.2 Función cuadrática base

La forma principal es y=a(x-h)²+k. El vértice es S(h;k); a controla la apertura y k desplaza la curva verticalmente.

3.3 Parámetro controlado por distancia

Un sensor de distancia puede controlar a, por ejemplo a=0,02d. Si d aumenta, el parámetro aumenta y la curva se vuelve más cerrada si a>0.

3.4 Sonido y desplazamiento vertical

Un nivel sonoro puede controlar k o c, por ejemplo k=s/10. El sonido desplaza entonces la curva hacia arriba o hacia abajo.

3.5 Calibración lineal

Si un parámetro debe pasar de un valor inicial a un valor final, se usa p=mx+b. La pendiente se calcula con m=(p₂-p₁)/(x₂-x₁).

3.6 Límites e inecuaciones

Para evitar valores peligrosos o ilegibles, se impone una cota: por ejemplo a≤1,5. Se resuelve una inecuación y se escribe una regla de saturación.

3.7 Módulos LED y restos

Para repartir LED sobre una curva, se cuentan intervalos, se elige una distribución entera y se calcula el resto para margen, señal o reserva de seguridad.

4. Modelo matemático: de un sensor a una obra

Rutina general: medir → identificar el dato → aplicar una regla → calcular un parámetro → limitar la respuesta → producir una salida visual.

Modelo A · Sensor de distancia → apertura

  1. El sensor mide d.
  2. Se define una regla, por ejemplo a=md+p.
  3. Se calcula a para distancias clave.
  4. Se usa y=a(x-h)²+k y se verifica la altura máxima.

Modelo B · Sonido → desplazamiento vertical

  1. El micrófono mide un nivel s.
  2. Se transforma en k=ms+p.
  3. Se comprueba el rango de k.
  4. Se interpreta el desplazamiento como energía visual.

Modelo C · LDR → brillo LED

  1. La LDR mide la luz ambiente L.
  2. Se calcula B=2L+20 o una regla similar.
  3. Se construye una tabla.
  4. Se limita el brillo si supera el máximo técnico.

Modelo D · Pseudocódigo

Un algoritmo básico puede escribirse: SI d está en un intervalo, ENTONCES se activa una salida asociada..

Observa la cadena: presencia del visitante, dato medido y respuesta visual.

5. Procedimientos matemáticos

Método 1 · Calcular un parámetro

  1. Identifico la variable medida.
  2. Sustituyo en la regla.
  3. Calculo el parámetro.
  4. Interpreto el efecto visual.

Método 2 · Calibrar linealmente

  1. Escribo dos condiciones.
  2. Calculo la pendiente.
  3. Encuentro la constante.
  4. Compruebo con los dos valores extremos.

Método 3 · Limitar una respuesta

  1. Identifico el límite.
  2. Resuelvo la inecuación.
  3. Escribo una regla SI...ENTONCES.
  4. Justifico la seguridad y la legibilidad.

Método 4 · Optimizar LED

  1. Calculo el número de intervalos.
  2. Elijo LED por unidad.
  3. Calculo uso total y resto.
  4. Decido qué hacer con el resto.

Método 5 · Leer una forma de vértice

  1. Identifico h y k.
  2. Escribo el vértice (h;k) y el eje x = h.
  3. Utilizo el signo de a para decidir el sentido de apertura.
  4. Indico si el vértice es máximo o mínimo.

Método 6 · Escribir intervalos sin solapamiento

  1. Ordeno los límites.
  2. Decido dónde se incluye cada extremo.
  3. Compruebo que cada distancia pertenece a un único intervalo.
  4. Pruebo un valor interior y cada valor límite.
Errores a evitar:
  • Confundir dato de sensor y parámetro matemático.
  • No convertir una condición verbal en ecuación.
  • Olvidar verificar la altura máxima del soporte.
  • Proponer interactividad sin regla matemática verificable.

7.2. Sensores y participación

7.2. Sensores y participación

Un sensor convierte una propiedad del entorno, como distancia, sonido o luz, en un dato que puede ser procesado. Organiza valores en una tabla, calibra una regla sencilla y comprueba sus extremos.

Pulse Room, instalación de luz: identifica entrada, respuesta, recorrido o escala.

El arte interactivo hereda el arte cinético de Soto, Cruz-Diez y Le Parc, pero añade sensores, computadoras y código para modificar el comportamiento de la obra en tiempo real.
