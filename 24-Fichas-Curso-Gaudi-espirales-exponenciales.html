C5 · Validar

Idea clave: una espiral real o un ornamento de Gaudí no se reduce a una fórmula. El modelo matemático sirve para mirar mejor, medir, comparar, justificar y crear.

3. Resumen matemático

Rutina DNL

  1. Observo el centro, el sentido de giro, las vueltas y la separación entre brazos.
  2. Elijo un modelo: crecimiento lineal, multiplicativo, Fibonacci o modelo multiplicativo sencillo.
  3. Calculo radios o valores en una tabla.
  4. Comparo el crecimiento: ¿aumento constante o multiplicación regular?
  5. Concluyo explicando utilidad, estética y límites del modelo.

Frases útiles

  • «El radio aumenta de manera constante: es un crecimiento lineal.»
  • «El radio se multiplica por el mismo factor: es un crecimiento multiplicativo.»
  • «La sucesión de Fibonacci se obtiene sumando los dos términos anteriores.»
  • «El modelo es aceptable porque todos los errores son pequeños.»
  • «El ornamento se parece a una espiral, pero no es necesariamente una espiral exacta.»
Antes de resolver: identifica si la variable representa el ángulo θ, el número de vueltas n o el número de paso; no confundas crecimiento lineal y multiplicativo.

4. Modelos de crecimiento

4.1 Espiral de Arquímedes

En un modelo escolar discreto, el radio puede aumentar una cantidad constante de un paso al siguiente.

r(n) = r₀ + d·n

r₀ es el radio inicial, d el aumento constante y n el número de paso.

4.2 Crecimiento lineal por vueltas

Si el radio aumenta la misma cantidad en cada vuelta, se puede usar una fórmula discreta.

r(n) = r₀ + d·n

r₀ es el radio inicial; d es el aumento por vuelta; n es el número de vueltas.

4.3 Crecimiento multiplicativo por pasos

Si el radio se multiplica por el mismo factor en cada vuelta, se usa un modelo discreto de

r(n) = r₀ · k^n

k es el factor de crecimiento. La espiral logarítmica se presenta como contexto visual; no se calculan logaritmos.

4.4 Crecimiento multiplicativo con potencias

Un modelo multiplicativo representa un crecimiento proporcional a lo que ya existe.

f(x) = a·b^x

a es el valor inicial y b es el factor multiplicativo.

4.5 Fibonacci y número áureo

La sucesión de Fibonacci se obtiene sumando los dos términos anteriores.

1, 1, 2, 3, 5, 8, 13, 21, ...
φ ≈ 1,618

Las razones entre términos consecutivos se aproximan progresivamente al número áureo.

4.6 Validar un modelo

Un modelo se valida comparando sus valores con medidas reales o restricciones.

error absoluto = |medida real − valor del modelo|

Si todos los errores son menores que el umbral fijado, el modelo puede aceptarse.

Modelo ≠ realidad: un ornamento arquitectónico depende de escala, material, mano artesanal, función y simbolismo. La ecuación solo es una herramienta de lectura.
  • ¿El crecimiento es lineal (suma constante) o multiplicativo (factor constante)?
  • Si r=aθ: ¿θ está en radianes o en “vueltas” (n)? No los confundas.
  • En una tabla: ¿miras diferencias (lineal) o cocientes (multiplicativo)?
  • En f(x)=a·b^x: a es valor inicial (x=0) y b es el factor.
  • ¿He escrito unidades y una frase de interpretación?
  • Si valido: ¿he calculado errores absolutos |real−modelo|?
Errores típicos: confundir θ y n (vueltas), confundir suma constante con multiplicación constante, olvidar que 2^0=1, y modelizar sin convertir la escala.

5. Procedimientos

Método A · Calcular con r = aθ

  1. Identifico el valor de a.
  2. Sustituyo θ por el valor pedido.
  3. Multiplico a·θ.
  4. Indico la unidad del radio.
  5. Concluyo si el crecimiento es lineal.

Método B · Completar una tabla de radios

  1. Escribo la fórmula del modelo.
  2. Sustituyo cada valor de θ o de n.
  3. Organizo los resultados en una tabla.
  4. Comparo las diferencias o los cocientes.
  5. Interpreto el tipo de crecimiento.

Método C · Usar Fibonacci

  1. Escribo los términos conocidos.
  2. Sumo los dos últimos para obtener el siguiente.
  3. Calculo razones consecutivas si se pide.
  4. Comparo con φ≈1,618.
  5. Redacto una frase prudente sobre patrones naturales.

Método D · Calcular un factor multiplicativo

  1. Identifico radio inicial y radio final.
  2. Escribo una ecuación multiplicativa.
  3. Pruebo un valor simple de k si el ejercicio es guiado.
  4. Compruebo sustituyendo en la fórmula.
  5. Interpreto el significado de k.

Método E · Usar una escala

  1. Comparo medida en foto y medida real.
  2. Calculo qué representa 1 cm.
  3. Convierto los radios necesarios.
  4. Modelo solo con medidas coherentes.
  5. Indico claramente la unidad.

Método F · Validar con errores absolutos

  1. Leo valores del modelo y las medidas reales.
  2. Calculo |real − modelo| para cada punto.
  3. Comparo con el umbral aceptado.
  4. Decido si el modelo es aceptable.
  5. Explico una causa posible de las diferencias.
