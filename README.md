# Seconde Module 1 révisé

Les deux versions ont été harmonisées sur les plans pédagogique, didactique et scientifique.

Principales modifications : problématique directrice, objectifs linguistiques DNL, réussite minimale, base 20 régulière distinguée du calendrier maya, quipu présenté comme modèle scolaire simplifié, analyse géométrique prudente des céramiques nazca, débat fondé sur des usages et critères, exposition préparée progressivement, grille d’évaluation commune et numérotation 1 à 7.

Les fichiers conservent les références existantes vers `module1.min.css` et `module1.min.js`.
