2. Resumen matemático: crear con funciones cuadráticas

2.1 Formas de una función cuadrática

Forma desarrollada: f(x)=ax²+bx+c. Forma canónica: f(x)=a(x-h)²+k. La forma canónica es la más útil para diseñar porque permite leer directamente el vértice.

2.2 Vértice, eje y apertura

En y=a(x-h)²+k, el vértice es S(h;k) y el eje es x=h. Si a>0, la curva se abre hacia arriba; si a<0, se abre hacia abajo.

2.3 Papel del parámetro a

Cuanto mayor es |a|, más estrecha es la parábola. Para una instalación “muy abierta”, se elige un valor pequeño de |a|.

2.4 Escala

Si 1 unidad = 5 cm, entonces el punto (4;3) corresponde a 20 cm horizontalmente y 15 cm verticalmente.

2.5 Desarrollo

Para pasar de la forma canónica a la forma desarrollada: (x-h)²=x²-2hx+h², después se multiplica por a y se añade k.

2.6 Módulos y restricciones

Un módulo es una unidad repetida de construcción. Para verificar una restricción, se usan la división entera, el resto, la longitud utilizada y el margen restante.

2.7 Problema inverso de escala

Cuando la maqueta impone una altura máxima, se calcula la escala máxima: escala = altura real máxima / altura matemática máxima.

3. Modelo matemático: de la ecuación a la instalación

Rutina general: idea visual → elección de función → cálculo de puntos → escala → verificación de restricciones → elección de materiales → argumentación.

Modelo A · Curva definida por un vértice

  1. Elijo el vértice S(h;k).
  2. Escribo y=a(x-h)²+k.
  3. Elijo el signo de a según la apertura.
  4. Calculo varios puntos para construir la curva.

Modelo B · Curva que pasa por un punto

  1. Parto de la forma canónica con el vértice conocido.
  2. Sustituyo x y y por el punto dado.
  3. Resuelvo para encontrar a.
  4. Compruebo que el punto pertenece a la curva.

Modelo C · Instalación a escala

  1. Calculo la escala en cm por unidad.
  2. Transformo cada coordenada.
  3. Verifico anchura y altura máximas.
  4. Si no cabe, reduzco la escala o modifico el modelo.

Modelo D · Obra con módulos

  1. Calculo la longitud de un módulo.
  2. Calculo cuántos módulos caben.
  3. Calculo el espacio restante.
  4. Compruebo si el patrón cromático se repite un número entero de veces.
Observa líneas, repetición, altura, simetría y relación con el espectador.

4. Procedimientos matemáticos

Método 1 · Calcular puntos

  1. Sustituyo el valor de x.
  2. Calculo el paréntesis o el cuadrado.
  3. Multiplico por a.
  4. Sumo el término final.
  5. Interpreto la altura o posición.

Método 2 · Leer una forma canónica

  1. Identifico h y k.
  2. Escribo el vértice S(h;k).
  3. Leo el signo de a.
  4. Determino si hay máximo o mínimo.

Método 3 · Desarrollar

  1. Desarrollo (x-h)².
  2. Multiplico por el coeficiente.
  3. Añado el desplazamiento vertical.
  4. Reduzco en forma ax²+bx+c.

Método 4 · Verificar una restricción

  1. Identifico la anchura o altura máxima.
  2. Calculo los valores correspondientes.
  3. Comparo con el límite.
  4. Propongo un ajuste si no se respeta la restricción.
Errores a evitar:
  • Confundir (x-4)² con un vértice de abscisa -4.
  • Olvidar la escala al pasar del dibujo a la maqueta.
  • Elegir materiales sin justificar la relación con la función.
  • Dar una función sin verificar que cabe en el soporte.
