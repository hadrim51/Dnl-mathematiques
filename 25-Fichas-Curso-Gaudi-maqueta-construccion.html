1. Competencias

Esta ficha prepara directamente el proyecto de trabajo: convertir dimensiones con una escala 1:n, comparar escalas, construir tablas de piezas, calcular un presupuesto, controlar una tolerancia, estudiar una estabilidad simplificada y modelizar un arco simétrico.

C1 · Convertir

Pasar de metros reales a centímetros de maqueta mediante escalas como 1:100, 1:150, 1:200 o 1:n.

C2 · Organizar

Construir tablas de piezas, cantidades, longitudes, costes, materiales y responsables.

C3 · Modelizar

Usar proporcionalidad, función de escala, función afín de coste y parábola escolar para un arco.

C4 · Restringir

Formular y resolver restricciones simples: altura máxima, presupuesto máximo, tolerancia o espacio disponible.

C5 · Validar

Comprobar estabilidad, compatibilidad, simetría, verticalidad, tolerancias y coherencia de las unidades.

C6 · Comunicar

Explicar en español: escala elegida, cálculos, modelo, límites y utilidad de la maqueta.

Idea clave: una maqueta es un modelo matemático y material: no copia todo, sino que selecciona, mide, simplifica, justifica y comunica.

  • «La tolerancia aceptada es de ±2 mm, por tanto la pieza debe medir entre…»
  • «El coste se modeliza con una función afín porque hay un coste fijo y un coste variable.»

Antes de construir: todas las piezas deben compartir la misma escala, las mismas unidades y un margen de tolerancia común.

4. Modelos y cálculos

4.1 Escala 1:n

Si la escala es 1:n, la medida de maqueta es la medida real dividida por n, con unidades coherentes.

medida maqueta = medida real / n

Procedimiento: convertir primero los metros a centímetros y dividir después por el denominador n.

4.2 Función de escala

Para estudiar la altura de una maqueta según el denominador n de la escala:

h(n) = H_real_en_cm / n

Esta función permite comparar 1:100, 1:150, 1:200 y resolver restricciones.

4.3 Restricción de altura

Si la maqueta debe medir como máximo 90 cm y la altura real simplificada es 172 m:

17200 / n ≤ 90

La desigualdad permite decidir qué escalas son posibles.

4.4 Tolerancia

Una tolerancia es un margen de error aceptable.

medida mínima = medida objetivo − tolerancia
medida máxima = medida objetivo + tolerancia

Una tolerancia ±t produce el intervalo [objetivo−t ; objetivo+t].

4.5 Función afín de coste

Un presupuesto combina un coste fijo y un coste variable.

C(x) = coste fijo + coste unitario × x

Se usa para calcular el máximo de piezas comprables con un presupuesto dado.

4.6 Arco parabólico simplificado

Un arco simétrico de maqueta puede modelizarse por una parábola escolar.

y = ax² + c

La clave da c; un apoyo permite calcular a. La parábola es una aproximación, no una catenaria exacta.

Modelo ≠ realidad: la Sagrada Familia es un edificio complejo. La maqueta escolar conserva proporción, estructura visible y explicación, pero elimina muchos detalles.
  • ¿He puesto todas las medidas en la misma unidad (cm o mm)?
  • ¿He aplicado bien 1:n (dividir por n)?
  • ¿He comprobado que altura ≤ 90 cm (o la restricción dada)?
  • ¿Mis tolerancias están como intervalo [min; max]?
  • ¿Si uso C(x)=ax+b, sé qué es x (número de placas/piezas)?
  • ¿Termino con una frase de interpretación + límite del modelo?
Errores típicos: mezclar m y cm, confundir 1:100 con 100:1, redondear hacia abajo en compras, olvidar margen de corte, y justificar sin unidades.
Ejemplo independiente: para una longitud real de 30 m a escala 1:150, se convierten 30 m en 3 000 cm y después se calcula 3 000÷150. Este ejemplo muestra el procedimiento sin resolver los datos de la ficha de trabajo.

5. Procedimientos

Método A · Convertir una escala

  1. Convierto la medida real a la unidad deseada.
  2. Divido por el denominador de la escala.
  3. Escribo la medida de maqueta.
  4. Compruebo que la dimensión es práctica.
  5. Justifico la elección.

Método B · Comparar escalas

  1. Calculo las dimensiones para cada escala.
  2. Comparo longitud, anchura y altura.
  3. Verifico espacio disponible y transporte.
  4. Elijo la maqueta más grande realizable.
  5. Explico el compromiso entre detalle y practicidad.

Método C · Controlar una tolerancia

  1. Identifico la medida objetivo.
  2. Resto la tolerancia para el mínimo.
  3. Sumo la tolerancia para el máximo.
  4. Compruebo si la pieza medida está en el intervalo.
  5. Decido si se acepta o se corrige.

Método D · Calcular un presupuesto

  1. Identifico costes unitarios y cantidades.
  2. Multiplico cada cantidad por su precio.
  3. Sumo todos los costes.
  4. Si hay una función C(x), interpreto x.
  5. Resuelvo la restricción de presupuesto.

Método E · Verificar estabilidad

  1. Identifico la base y su semianchura.
  2. Localizo la proyección del centro.
  3. Compruebo si queda dentro de la base.
  4. Propongo refuerzos si sale fuera.
  5. Redacto una conclusión técnica.

Método F · Construir un arco parabólico

  1. Uso la simetría para elegir y = ax² + c.
  2. Uso el punto alto para encontrar c.
  3. Uso un apoyo para encontrar a.
  4. Completo una tabla de valores.
  5. Señalo el límite del modelo.

Unidades

m→cm: multiplicar por 100; cm→mm: multiplicar por 10.

Traducir «como máximo» por ≤ y «como mínimo» por ≥.

Compatibilidad

Comparar diámetro de la pieza y diámetro del agujero.

Conclusión

Resultado + unidad + decisión + límite del modelo.
