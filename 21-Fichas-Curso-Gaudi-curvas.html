1. Competencias

Esta ficha prepara las tareas de la ficha de trabajo: reconocer curvas, leer ecuaciones simples, construir modelos, interpretar parámetros y explicar los límites de una modelización arquitectónica.

C1 · Reconocer

Identificar parábola, catenaria, espiral y sinusoide en formas inspiradas en Gaudí.

C2 · Representar

Usar coordenadas, tabla de valores, eje de simetría, vértice, amplitud y altura media.

C3 · Calcular

Calcular valores de una función, una escala, una amplitud, una altura máxima o un error absoluto.

C4 · Modelizar

Elegir una ecuación sencilla para aproximar una forma: parábola, sinusoide o crecimiento radial.

C5 · Validar

Comparar el modelo con datos y decidir si la aproximación es aceptable.

C6 · Comunicar

Redactar una justificación en español: observo, elijo, calculo, verifico y concluyo.

Idea clave: una curva arquitectónica real no coincide siempre exactamente con una fórmula escolar. En clase usamos modelos para simplificar, comparar y argumentar.

3. Herramientas

Rutina DNL

  1. Observo la forma y sus rasgos: simetría, repetición, crecimiento, ondulación.
  2. Elijo un modelo razonable.
  3. Calculo algunos valores o parámetros.
  4. Verifico si el modelo se parece bastante a la forma.
  5. Concluyo explicando los límites del modelo.

Frases útiles

  • «La curva se parece a una parábola porque tiene un eje de simetría.»
  • «El parámetro a cambia la apertura de la curva.»
  • «La amplitud mide la distancia entre la altura media y un máximo.»
  • «El modelo es útil, pero no describe todos los detalles del edificio.»
Antes de resolver un ejercicio: identifica las unidades, el sistema de coordenadas y lo que representa cada parámetro.

4. Curvas

4.1 Parábola — arco escolar simple

Una parábola es la curva de una función cuadrática. Es práctica para modelizar un arco simétrico.

y = ax² + bx + c

Si el eje de simetría es vertical y el vértice está en (0; h), usamos a menudo:

y = ax² + h

Lectura: si a es negativo, la curva se abre hacia abajo; cuanto más negativo es a, más cerrado parece el arco.

4.2 Catenaria — cadena suspendida

La catenaria es la forma de una cadena que cuelga entre dos puntos. Invertida, permite imaginar un arco que trabaja bien en compresión.

Modelo cualitativo: cadena suspendida e imagen invertida

En clase: no hace falta calcularla; interesa compararla con una parábola y entender que se parece, pero no es igual.

4.3 Sinusoide — ondulación regular

Una ondulación regular puede describirse mediante una altura media D y una amplitud A. En segundo se usan estos dos parámetros sin calcular valores trigonométricos.

máximo = D + A ; mínimo = D − A

A es la amplitud; D es la altura media. Como sin(x) está entre -1 y 1, el máximo vale D + A y el mínimo D − A.

4.4 Espiral — giro y crecimiento

Una espiral gira alrededor de un centro y se aleja progresivamente. Puede aparecer en motivos decorativos, chimeneas o formas orgánicas.

Modelo discreto simple: r = r₀ + k·n

Lectura: si k es positivo, el radio aumenta en cada paso: hay crecimiento progresivo.

5. Métodos

Método A · Calcular valores de una parábola

  1. Sustituyo x por el valor dado.
  2. Calculo x².
  3. Multiplico por el coeficiente.
  4. Añado la constante.
  5. Interpreto la altura obtenida.

Método B · Construir una parábola con el vértice

  1. Identifico el vértice V(0; h).
  2. Uso la forma y = ax² + h.
  3. Sustituyo un punto conocido del arco.
  4. Resuelvo para encontrar a.
  5. Compruebo con un punto simétrico.

Método C · Leer una sinusoide

  1. Identifico la altura media D.
  2. Identifico la amplitud A.
  3. Calculo máximo: D + A.
  4. Calculo mínimo: D − A.
  5. Redacto una frase sobre la ondulación.

Método D · Validar un modelo

  1. Calculo los valores dados por el modelo.
  2. Comparo con las medidas reales.
  3. Calculo el error absoluto: |real − modelo|.
  4. Comparo con el umbral aceptado.
  5. Concluyo: aceptable o no, con una justificación.
Escala: si 6 cm en una foto representan 12 m reales, entonces 1 cm representa 2 m. Antes de modelizar, todas las medidas deben estar en unidades coherentes.
