Frases útiles

4. Modelos lineales

4.1 Pendiente

La pendiente indica cuánto sube o baja una línea cuando avanzamos horizontalmente.

pendiente = Δy / Δx = (y₂ − y₁) / (x₂ − x₁)

Interpretación: si la pendiente es 0,5, la línea sube 0,5 unidad por cada unidad horizontal. En porcentaje: 50%.

4.2 Función afín

Una función afín representa una recta que no pasa necesariamente por el origen.

y = ax + b

a es la pendiente; b es el valor inicial u ordenada al origen.

4.3 Recta por dos puntos

Si conocemos dos puntos A(x₁;y₁) y B(x₂;y₂), podemos construir el modelo de una línea estructural.

a = (y₂ − y₁)/(x₂ − x₁), luego b = y₁ − a·x₁

Uso: eje de una columna, borde de una cubierta, línea de una barandilla o dirección simplificada de una fuerza.

4.4 Carga repartida constante

Una carga uniforme sobre una viga puede representarse por una función constante.

p(x) = k

Si una viga de longitud L soporta una carga total P, entonces k = P/L.

4.5 Momento de fuerza

En este modelo simplificado, una fuerza perpendicular situada a una distancia d del apoyo produce un momento.

M = F × d

Si F no cambia, el momento aumenta proporcionalmente con d. La unidad usada es N·m.

4.6 Modelo lineal de coste

Un coste con parte fija y parte proporcional a una longitud se modeliza con una función afín.

C(x) = coste fijo + coste por metro × x

Este modelo sirve para resolver restricciones simples de presupuesto.

Límite didáctico: estas fórmulas son simplificaciones. Un edificio real incluye peso propio, viento, materiales, uniones, seguridad y deformaciones que no siempre son lineales.

5. Métodos

Método A · Calcular una pendiente

  1. Identifico la subida Δy.
  2. Identifico el avance horizontal Δx.
  3. Calculo Δy/Δx.
  4. Transformo en decimal o porcentaje si se pide.
  5. Interpreto: poca, media o fuerte inclinación.

Método B · Encontrar una ecuación de recta

  1. Calculo la pendiente con dos puntos.
  2. Uso y = ax + b.
  3. Sustituyo un punto para encontrar b.
  4. Escribo la ecuación completa.
  5. Compruebo con el otro punto.

Método C · Calcular una carga repartida

  1. Identifico la carga total P.
  2. Identifico la longitud L.
  3. Calculo k = P/L.
  4. Escribo p(x)=k.
  5. Para un tramo de longitud t, calculo k×t.

Método D · Calcular o equilibrar momentos

  1. Identifico la fuerza F.
  2. Identifico la distancia d al apoyo.
  3. Calculo M = F×d.
  4. Para equilibrio, igualo los momentos de cada lado.
  5. Interpreto con unidades N·m.

Método E · Usar una escala

  1. Comparo medida en la foto y medida real.
  2. Calculo qué representa 1 cm.
  3. Convierto todas las medidas necesarias.
  4. Calculo la pendiente o la distancia real.
  5. Verifico que las unidades son coherentes.

Método F · Validar un modelo lineal

  1. Calculo los valores dados por el modelo.
  2. Comparo con las medidas reales.
  3. Calculo el error absoluto: |real − modelo|.
  4. Comparo con el umbral aceptado.
  5. Concluyo con una frase justificada.

Si una magnitud se duplica y el resultado se duplica, el modelo es proporcional.
